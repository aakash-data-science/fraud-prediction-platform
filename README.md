# 🛡️ Fraud Detection Platform

An end-to-end Machine Learning Fraud Detection Platform built using Python, Scikit-learn, FastAPI, Streamlit, and SQLite.

The application predicts whether a financial transaction is **Fraud** or **Legitimate** using a trained machine learning model and provides an interactive dashboard for monitoring model performance.

---

# 🚀 Features

- Real-time Fraud Prediction
- FastAPI REST API
- Interactive Streamlit Dashboard
- Model Performance Dashboard
- Prediction History
- SQLite Database Integration
- Feature Importance Visualization
- ROC Curve
- Precision-Recall Curve
- Confusion Matrix
- Logging Support

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/aakash-data-science/fraud-prediction-platform.git
```

Move into the project

```bash
cd fraud-prediction-platform
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run FastAPI

```bash
uvicorn api.main:app --reload
```

Run Streamlit

```bash
streamlit run app/streamlit_app.py
```
