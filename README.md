# 🛡️ Enterprise Fraud Detection & Risk Analysis Platform

An end-to-end Machine Learning application that detects fraudulent financial transactions using advanced classification models. The platform provides real-time fraud prediction, interactive analytics, prediction history, and model performance visualization through a professional Streamlit dashboard.

## 📖 Project Overview

Financial fraud causes significant losses for organizations every year. This project demonstrates an end-to-end fraud detection pipeline that processes transaction data, predicts fraudulent activity using machine learning, and presents insights through an interactive dashboard.

The platform includes:

- Real-time fraud prediction
- Fraud probability estimation
- Interactive analytics dashboard
- Prediction history
- Model performance visualization
- Downloadable prediction reports
- Cloud deployment using Streamlit Community Cloud

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/aakash-data-science/fraud-prediction-platform.git
```

## Navigate to Project

```bash
cd fraud-prediction-platform
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Launch Application

```bash
streamlit run app/streamlit_app.py
```
